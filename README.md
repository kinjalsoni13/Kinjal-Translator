

# Kinjal Translator

A single-file, self-contained multi-language translator web app.

## What's inside
- `kinjal-translator.html` — the whole app (HTML + CSS + JS in one file). No install, no build step.

## How it works
- Type text, pick a source language (or leave it on Auto-detect) and a target language, then hit **Translate** (or press ⌘/Ctrl+Enter).
- Translation is done by calling a free public translation endpoint directly from the browser — no API key, no backend, no sign-up needed.
- Swap languages with the ⇄ button, copy the result, or clear the text.

## Running it
1. Unzip this folder.
2. Double-click `kinjal-translator.html` to open it in your browser.
3. Make sure you're connected to the internet — the translation call needs it.

That's it — it works fully standalone, offline-installed but online-translating.
